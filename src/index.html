How the lab works

Reproducible, no-cost, and careful about what public profiles can tell us.

  1. Validate LinkedIn and Instagram URLs against their official domains.
  2. Attempt one anonymous server-side fetch per profile. If a platform blocks it, the user can paste visible public text from that same page.
  3. Extract a small dictionary of explicit public topics. The source links and excerpts remain visible on each profile.
  4. Each advocate dates every other agent through a fictional, evidence-based conversation prompt.
  5. Rank all candidates by weighted topic overlap and adjacent-topic bridges. Scores never represent real attraction or intent.
Instagram and LinkedIn can limit anonymous access. The reader reports that limitation and does not sign in, bypass access controls, or invent missing source text.
