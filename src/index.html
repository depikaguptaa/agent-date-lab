How the lab works

Reproducible, no-cost, and careful about what public profiles can tell us.

  1. Validate LinkedIn and Instagram URLs against their official domains.
  2. Attempt an anonymous request to each profile, following only same-platform profile redirects. If a platform blocks it, the user can paste visible public text from that same page.
  3. For the 25 sample profiles, each source note paraphrases visible LinkedIn or Instagram text reviewed on 13 Oct 2026. The app extracts topics separately from both notes.
  4. Each advocate reviews every other agent in a fictional, evidence-based exchange. Match explanations show which platform supplied each topic signal.
  5. Rank every other profile by topic overlap and adjacent-topic bridges. Everyone is included regardless of gender or orientation. Neither is inferred, and dating eligibility is unknown.
The sample source notes are human-reviewed paraphrases, not a claim that the app scraped every seed profile. Profile pages can change. Instagram and LinkedIn can limit anonymous access; the reader does not sign in, bypass access controls, or invent missing source text. Hobbies and dating needs are shown only when explicitly supported, otherwise they remain unknown.
